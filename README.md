# Eldar Sarajlić — Portfolio

Personal portfolio website built with React, TypeScript, and Vite. Features animated sections, detailed project case studies, and a clean dark design with mint accents.

## Tech Stack

- **React 19** + **TypeScript** — component architecture and type safety
- **Vite** — fast dev server and build tooling
- **Framer Motion** — scroll-triggered animations and page transitions
- **Tailwind CSS** — utility-first styling
- **React Router** — client-side routing for project detail pages
- **React Bits** — animated UI component primitives

## Features

- Animated hero, about, skills, experience, projects, education, and contact sections
- Custom animation components: `SplitText`, `ShinyText`, `Reveal`, `Magnetic`, `Aurora`, `HexGrid`
- Detailed case study pages for featured projects
- Responsive, mobile-first layout

## Getting Started

```bash
npm install
npm run dev
```
